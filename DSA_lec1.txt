O(1)= Constant time
array=[1,2,3,4,5]
array[1]==array[2]
requires same time to access any element
Use case--accessing a specific element in an array


O(n)= Linear time
array=[1,2,3,4,5]
for element in array:
     print(element)
Use case--loop through array elements

O(log n)= Logarithmic time
visit only some elements
Use case--binary search

O(n^2)= Quadratic time
for x in array:
  for y in array:
     print(x,y)
Use case--looking at every index in the array twice(nested loop)

O(2^n)= Exponential time
def finbonacci(n):
     if n <= 1:
         return n
     return fibonacci(n-1) + fibonacci(n-2)
Use case--double recurssion in fibonacci

===============Day 8==================
-----------binary tree----------
Full binary tree-
1. each node has either 0 or 2 childeren
2. no node has a single child

Complete binary tree-
1. all levels except possibly the last one are completely filled
2. nodes in the last level are filled from left to right

Perfect binary tree-
1. all internal nodes have exactly two nodes
2. all leaf nodes are at the same level

Operations:
-Creation of tree
-Insertion of a node
-Deletion of nodes
-Search for a value
-Traverse all nodes
-Deletion of tree

Traversal: 1.BFS---level order traversal
           2.DFS --1) preorder  ---root-left-right
                   2) inorder   ---left-root-right
                   3) postorder ---left-right-root

Why binary search tree?
--- Its performs faster than binary tree when inserting and deleting nodes.
